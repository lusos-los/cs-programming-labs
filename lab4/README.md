# Лабораторная работа № 4 — Проверка условий

## Цель работы
Изучить условные конструкции Python и научиться выбирать результат в зависимости от входных данных.

## Состав работы
- `task1.py` — управление кондиционером.
- `task2.py` — расчёт стоимости билета.
- `task3.py` — определение положения точки на координатной плоскости.
- `task4.py` — проверка существования и определение типа треугольника.
- `task5.py` — определение високосного года.

## Запуск
Запускать каждую программу из корня репозитория командой:

`python .\lab4\task1.py`

Вместо `task1.py` укажи имя нужного файла.

## Ограничения
Ввод выполняется через `input()`. Для выбора результата используются условные конструкции. Циклы не применяются.

## Проверка
Результаты работы программ необходимо сверить с примерами и граничными случаями из задания.
